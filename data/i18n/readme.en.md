
# Kan<sup>Tan</sup>Ji &nbsp; 漢<sup>単</sup>字

> Simple Kanji training platform.

A simple application for practising Kanji. The project started as a collaboration
of volunteers and Japanese-studies students at FF MUNI. Its goal is to offer
multiple ways of learning kanji with complete supporting information.

[Your feedback is valuable to us! Please contact us on the project page.](https://github.com/KanjiBase/KanTanJi/issues)
The same link can be used to contribute to the database.
If you would like to help with content preparation or have another idea, please let us know.

Kan<sup>Tan</sup>Ji is an open-source project and has no affiliation with any existing social-media profiles.

### FAQ
<details>
<summary>What is the project status?</summary>
Kan<sup>Tan</sup>Ji may contain minor mistakes, typically caused by human error while entering thousands of words
and example sentences — please let us know if you find any! The Japanese school-system orderings are complete
up to the last set, which may be missing a few characters that have not yet appeared in the BKB ordering. The BKB
ordering itself is complete with respect to the existing set. In the future we plan to keep growing the number of
supported kanji.
</details>
<details>
<summary>
Character ordering and set sizes
</summary>
The orderings and set sizes are not designed to please everyone. Orderings are available per the chapters listed
below. For every ordering, all material types (PDF, Anki, HTML pages, etc.) are produced.
In the future we would like to expand the range of tools available for studying kanji and let users define their own
orderings and set sizes.
</details>
<details>
<summary>Filtering Anki cards</summary>
KanTanJi cards may contain more than you want to study. Cards can be filtered easily using <strong>tags</strong>. The currently available tags are:
<ul>
 <li><strong>KanTanJi_Kanji</strong> (a kanji card)</li>
 <li><strong>KanTanJi_Tango</strong> (vocabulary related to a kanji)</li>
 <li><strong>KanTanJi_Learn_Now</strong> (vocabulary containing only kanji you have already learned)</li>
 <li><strong>KanTanJi_Learn_Deck</strong> (vocabulary containing kanji that will be learned in the current deck)</li>
 <li><strong>KanTanJi_Learn_Future</strong> (vocabulary containing kanji that have not yet been learned)</li>
</ul>
For example, to remove all kanji cards and any vocabulary that is too hard because it contains kanji you have not
yet learned in the KanTanJi ordering, you can <strong>suspend</strong> the cards tagged
'KanTanJi_Kanji' and 'KanTanJi_Learn_Future'.

First, <strong>open Browse Cards</strong> in Anki. Then in the options choose <strong>filter by tag</strong>.
Once only the desired cards are shown, choose <strong>select all cards</strong> from the options
and finally choose <strong>suspend</strong>.

We recommend merging the sets you study into one large deck so that you can take advantage of Anki's smart repetition.
</details>
